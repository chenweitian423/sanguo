# 乱世刀锋

原创街机式 **平面乱斗（beat-em-up）** 试玩。灵感来自华语三国题材街机乱斗的手感基因（八向走位、群战围殴、连招与必杀），但名称、武将、招式与美术均为 **原创 IP**，与任何商业作品无关。

## 如何打开

任选其一：

1. **直接打开**  
   用浏览器打开本目录下的 `index.html`。

2. **本地静态服务器（推荐，便于加载 PNG）**

       cd /workspace/sanguo-brawler
       python3 -m http.server 8080

   访问：http://127.0.0.1:8080/

无需构建工具：纯 HTML / CSS / JavaScript。

## 操作说明

| 操作 | 按键 |
|------|------|
| 八向移动（左右 + 纵深） | `A` `D` `W` `S` 或方向键 |
| 短跳（用于跳攻） | `空格` |
| 轻击连招（2～3 段，带硬直） | `J` |
| 必杀（气势槽或冷却） | `K` |
| 跳攻 | 滞空时按 `J` |
| 标题 / 选将 / 结算确认 | `Enter` / `空格`，或鼠标点击 |

流程：标题 → **选将（枪将 / 刀客 / 谋士）** → 一关战场 → 两波敌军。

## 玩法要点

- **地面平面**，不是平台跳跃闯关：角色在战场 X/纵深 上移动，绘制按纵深（脚底 Y）排序。
- **群战**：乱兵成群靠近并围攻；第一波约 4 人，第二波约 6 人 + 1 名精锐。
- **街机 HUD**：体力、气势、得分、波次（中文标签）。
- 场景使用 `assets/stage-battlefield.png`；枪将可引用 `assets/hero-spear.png` 精灵区域，其余武将为强化剪影。
